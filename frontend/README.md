# Dispatch Frontend

React + Vite + TypeScript + Leaflet untuk Dispatch Fase 2 (peta kendaraan + insiden + kandidat terdekat).

Lihat [README](../README.md) di root proyek untuk prasyarat, cara menjalankan, kredensial seed, dan daftar endpoint.

```powershell
npm install
npm run dev
npm run build
npm run lint
```

Konfigurasi API memakai environment variable:

```dotenv
VITE_API_BASE_URL=http://localhost:8080
```
